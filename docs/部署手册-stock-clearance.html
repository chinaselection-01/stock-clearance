stock-clearance.ai · 上线部署手册 MVP 静态版

目标：把现有的纯前端 MVP（index.html + styles.css + app.js）部署上线，并让 stock-clearance.ai 指向它。

✅ 文件已就绪：当前 MVP 是纯静态三件套，无构建步骤，可直接丢到任意静态托管（Vercel / Cloudflare Pages / Netlify）。部署只需这 3 个文件。
⚠️ 上线前必须知道的一个局限：当前版本数据存在访客各自的浏览器（localStorage）里。也就是说——你在我电脑/手机上发了一条尾货，别人打开网站看不到。这是"流程验证版"，不是生产版。真要让供应商和买家互相看得见、能撮合，需要下一步接 Supabase（见文末）。本手册先让域名活起来 + 验证界面。

一、选部署平台

平台适合场景成本自定义域名
Vercel（推荐）最简单，拖文件即部署，自动 HTTPS免费支持，DNS 用 CNAME
Cloudflare Pages若你的域名是在 Cloudflare 注册的，DNS 同面板一键最顺免费支持，同面板
Netlify备选，拖放部署免费支持

二、路径 A：Vercel（最省事）

步骤 1 注册 / 登录 Vercel

打开 vercel.com → 用 GitHub 或邮箱注册登录（免费个人版即可）。

步骤 2 部署

  1. 首页点 Add New → Project；
  2. 不选 Git 仓库也行——直接把本地这三个文件（index.html styles.css app.js）拖进上传区；
  3. Framework 选 Other，其余默认；
  4. 点 Deploy。约 30 秒后给你一个 https://stock-clearance-xxx.vercel.app 的临时域名，先点开确认网站正常。

步骤 3 绑定 stock-clearance.ai

  1. 进项目 Settings → Domains，输入 stock-clearance.ai，点 Add；
  2. Vercel 会提示你去域名注册商加一条 DNS 记录（见第三节）；
  3. 加完记录后回到 Vercel，状态会从 Invalid Configuration 变 Valid Configuration，通常 5 分钟~数小时生效。

三、DNS 配置（关键一步，在你注册商后台做）

无论用哪家托管，最后都要在 域名注册商（Cloudflare 或 Porkbun）后台加记录。两种做法二选一：

做法 1（推荐）：CNAME 指向托管平台

类型名称 / Name值 / Target
CNAMEstock-clearance.ai 或 @Vercel: cname.vercel-dns.com
Cloudflare Pages: 按后台提示填
Netlify: apex-loadbalancer.netlify.com

做法 2：A 记录指向平台 IP（某些平台提供）

若平台给了 IPv4（如 Vercel 的 76.76.21.21），可在注册商加：

类型: A
名称: @
值:   76.76.21.21
Cloudflare 注册商用户注意：在 Cloudflare 面板里域名已自动托管，直接在 DNS → Records 加上述 CNAME/A 即可，且 SSL/HTTPS 默认开启，无需额外操作。
Porkbun 注册商用户注意：进 Porkbun 后台 Domain Settings → DNS 加记录，SSL 也默认有。

四、上线前必改项清单

  • footer 免责句：当前写着"MVP demo·数据存于本地浏览器"——上线正式招商前把这句改掉或弱化，免得买家/供应商看到以为是玩具。
  • robots.txt：确保没有屏蔽折扣/列表页（新手常犯）。可在根目录放一个 robots.txt：
    User-agent: *
Allow: /
  • sitemap.xml（可选，SEO 用）：上线后补一个，列出主要页面和品类页。
  • HTTPS：Vercel / Cloudflare / Netlify 都自动签发，无需手动。
  • 移动端：当前已做响应式，上线后用手机访问自检一遍。

五、上线后验证

  1. 浏览器开 https://stock-clearance.ai，确认跳 HTTPS 且网站正常；
  2. 命令行验证 DNS 生效：
    dig stock-clearance.ai +short
    应返回平台 IP 或 CNAME；
  3. 用手机走一遍：切换中英文 → 拍照发帖 → 提交询盘 → 看 Inquiries 红点。
⚠️ 建议补拿 stocklot.ai：你这次只注册了主域名。老外 B2B 买家实际搜的词是 stock lot（不是 stock clearance）。强烈建议回头把 stocklot.ai 也拿下，做 301 跳转到主站或镜像内容，接住那批精准流量。多一份钱，但很值。

六、已知局限 & 下一步

当前版本 = 验证版，数据不跨用户共享。要让平台真正撮合，下一步是接 Supabase（Postgres 后端即服务）：
  • 供应商发帖 → 写入数据库 → 所有访客都能看到；
  • 询盘写入数据库 → 供应商后台能看、能标记处理；
  • 图片真正上传存储（不再压成本地）；
  • 标题中文→英文自动翻译接真实 API。
这一步约几天工期，预算外包约 2–5 万。在此之前，你可以用"代运营"方式手动采集 100–300 条真实尾货，把界面填满做招商演示。
