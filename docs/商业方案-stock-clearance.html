一、我们到底做什么（一句话定位）

stock-clearance.ai = 全球尾货 B2B 撮合平台。把义乌五爱库存街、以及广东/浙江/福建等地产业带的工厂尾货、库存积压、清仓货，用结构化英文信息（图片 + 参数 + MOQ + 清仓价）组织起来，卖给海外折扣店、清货商、二手商、非洲/中东/东南亚批发商。

类比：闲鱼是 C 端个人闲置；1688 / Alibaba 是新品正品批发；我们是专门做「lot / stock / clearance」的 B2B 垂直版闲鱼，且天然面向老外。

二、为什么是蓝海（市场机会）

1. 尾货是海量刚需，且长期存在

每个产业带工厂都有生产尾单、订单取消、换季积压。清仓价是正常价的 1–3 折，对价格敏感的海外买家极具吸引力。这是"永远清不完"的供给。

2. 现有平台全部错位

  • 1688 / Alibaba.com：以新品、正品、高起订量为主，几乎不服务"低价尾货 lot"；
  • 闲鱼：C 端个人闲置，非跨境、非 B2B；
  • 线下义乌五爱库存街：全国最大库存商品集散地，但触达海外靠中介、层层抽佣、语言不通。

→ 一个专门服务 stock lot、且英文界面、面向老外的 B2B 平台，目前没有强垂直玩家。

3. 基础设施已成熟

跨境支付（PayPal / Payoneer / T/T）、国际物流（阿里系、货代）、翻译工具都已到位。剩下的缺口是"把尾货信息用英文结构化地摆出来 + 信任撮合"，这正是平台要补的。

需验证（不靠拍脑袋）：① 义乌五爱库存街线上化的真实供给规模；② 老外通过线上找中国尾货的付费意愿与获客成本；③ 主要目标国（非洲/中东/东南亚/南美）的采购习惯。这些应在 MVP 阶段用真实询盘数据验证，而非先做重。

三、双边痛点 & 平台价值

供给侧（国内工厂 / 档口 / 库存商）

  • 尾货分散、信息不对称，清货靠熟人 + 线下市场；
  • 不懂英文、不懂跨境，单个工厂没能力做独立站获客；
  • 被海外中介抽走多层差价。

平台价值：用中文填表 → 自动生成英文展示 → 直接触达老外。

需求侧（海外批发商 / 清货商）

  • 来义乌成本高、语言不通、找货靠中介；
  • 1688/阿里难找到"低价尾货 lot"；
  • 缺少可信的、按 lot 组织的清仓货源。

平台价值：一个英文界面，按品类 / 产业带 / 价格筛出真实库存。

四、冷启动策略（你的最大杠杆）

关键判断：这个生意最难的是"先有鸡还是先有蛋"。你破局靠的不是技术，而是你本人就是外贸老手——手上既有国内供应商（滑梯/杯壶/宠物用品产业带关系），又有海外买家（捷克 Aga24、Lulu 等）。起步速度远超纯技术团队。
1
先把货"填满"：从义乌五爱 + 你已有产业带关系，人工采集 100–300 条真实尾货（拍照 + 翻译），让平台上线即"看起来很满"。你当第一批"超级买手 / 撮合人"。
2
再把老外引来：SEO（stock lot / clearance / overstock + 品类词）、TikTok/YouTube 展示"中国尾货淘货"内容、Facebook 清货商群组、Google 精准词广告。
3
机器放大你的撮合：早期不做支付、不做复杂后台，做"带询盘功能的尾货展示站 + 你的人工撮合"，先验证老外是否真从这里下单。

五、盈利模式（带优先级建议）

你勾选了：成交抽佣 + 会员/年费 + 广告/置顶，且要我给建议。我的建议如下（按落地优先级）：

优先级模式怎么收理由 / 时机
P1 先上会员 / 年费 + 认证供应商付费发帖、多发、认证标、数据看板抽佣难收时（成交易绕开平台走 WhatsApp/线下），会员费是确定性现金，且筛出真供应商
P1 先上置顶 / 推广位类闲鱼"擦亮"，花钱买曝光供给多了才有价值，但可早期小范围试
P0 目标成交抽佣 3–8%撮合成交后按金额阶梯抽最干净的"平台型"变现，但依赖信任 + 支付闭环，闭环成熟后再主推
增量服务抽成验货/质检、代采佣金、物流撮合比纯信息撮合更好收钱，你有外贸经验能做
核心建议：早期别指望抽佣（成交极易绕开平台）。采用"供方付费优先、买方免费"的冷启动变现——先把供给侧的钱收上来（会员/认证/置顶），抽佣等信任和支付闭环建好后再上。

六、产品形态（对应设计稿页面）

  • 首页：双语切换、Hero、按产业带/品类导航、精选 stock lots、供应商招商入口；
  • 浏览 / 搜索页：按品类、产业带、价格、MOQ 筛选，卡片展示（图 + 英文标题 + 清仓价/原价 + MOQ + 所在地）；
  • 商品详情 / 询盘页：大图、英文参数表、数量阶梯价、MOQ、发货地、库存、"Request a Quote" 按钮（留资 / WhatsApp / 邮箱）；
  • 供应商发帖页：中文填表 → 前端自动生成英文展示；
  • 供应商后台：我的库存、询盘管理、会员权益、数据（未来）；
  • 买家中心：收藏、询盘记录、订单（未来）。

七、技术架构建议（给以后开发，本版不实现）

  • 前端：Next.js + Tailwind，内置中英 i18n；
  • 后台 / 数据：Supabase / Postgres（listings、users、inquiries）或 Django；
  • 图片：对象存储（Cloudflare R2 / 阿里 OSS）；
  • 支付：早期不强依赖（询盘制，成交线下/TT）；未来 Stripe / Payoneer；
  • 部署 / 域名：Vercel + 域名 stock-clearance.ai（.ai 域名约 $80–100/年）；
  • SEO 是生命线：静态化、结构化数据 schema、多语言 hreflang。

八、合规与风险（尾货专属坑）

  • 品牌侵权（头号大坑）：仿牌 / 侵权清仓是红线。必须设"无品牌 / 自有品牌 / 授权"字段 + 平台免责声明，审核上线；
  • 质检 / 认证：尾货出口目的国仍有认证要求（你做外贸懂 LVD/EMC/RoHS 等），详情页应标注；
  • 跨境收款合规：大额走对公 / 报关，避免私账大进大出；
  • 冷启动最大风险：双边都没量。对策＝你先亲自把供给侧填"满"，再用内容把买方引来。

十、我的核心判断（给你拍板用）

  1. 赛道方向对。且你有"supplier + buyer 双边资源 + 外贸经验"的稀缺起步优势，比纯草根团队成功率高得多。
  2. 破局点不是技术，是你亲自当第一批超级撮合人 + 用内容把老外引过来。
  3. 第一版别做重：不做支付、不做复杂后台，做"带询盘的尾货展示站 + 人工撮合"，先验证老外是否真从这里下单。
  4. 变现上供方付费（会员/认证/置顶）优先于抽佣，因为抽佣在信任闭环没建好前根本收不到。
